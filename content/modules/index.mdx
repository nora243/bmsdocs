# Modules

BMS được chia thành các module nghiệp vụ độc lập:

| Module | Mô tả |
|--------|-------|
| [Mua hàng](/modules/purchase) | Quản lý đặt hàng, nhập kho, công nợ phải trả |
| [Bán hàng](/modules/sales) | Quản lý đơn hàng, xuất kho, công nợ phải thu |
| [Kho](/modules/warehouse) | Quản lý tồn kho, phiếu nhập/xuất, kiểm kê |
| [Tài chính](/modules/finance) | Thu chi, công nợ, báo cáo tài chính |
| [Nhân sự](/modules/hr) | Quản lý nhân viên, KPI, chấm công |
| [Hệ thống](/modules/system) | Quản lý người dùng, vai trò và quyền hạn |
